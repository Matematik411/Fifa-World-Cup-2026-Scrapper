Line-up fixes — set these before kickoff

Each player locks at his own match kickoff, so until then you can freely move him between the XI and the bench (a line-up edit, not a transfer). These starters are not expected to play their next match — bench each and start the named replacement before the outgoing player's kickoff:

Free-roll starts — cash a bench player now, restore later (free)

Each of these bench players plays in the imminent window while a current starter doesn't play until a later day. Start the bench player now in that starter's slot — it's free (the parked starter scores nothing this window anyway). On a later run, restore him by subbing out whoever actually scored lowest. Downside-protected: if the player you bring in blanks, just put the starter back — net zero.

How it works: the captain can be changed during a live round only if the old captain's match has ended and the new one's hasn't started. Any manual change cancels this round's auto-subs, so only act when your remaining starters are confirmed in their line-ups.

{% if fantasy.playbook.bench_first %}

Blank rescue (after a match ends)

Distinct from the pre-kickoff fixes above: once a starter's match has ended with him on a blank (≤1 pt, or a late did-not-play you couldn't pre-empt), you can still swap him for a bench player whose match hasn't kicked off — first bench option {{ fantasy.playbook.bench_first.name }} (E {{ fantasy.playbook.bench_first.exp|r(1) }}, plays {{ fantasy.playbook.bench_first.date }}). You then score only the incoming player, and the replacement must play later than the man coming out (a same-match team-mate is no use). Any manual change — incl. moving the captain — cancels this round's auto-subs, so once you're managing the XI, handle every did-not-play yourself rather than trusting the end-of-round auto-fill.
